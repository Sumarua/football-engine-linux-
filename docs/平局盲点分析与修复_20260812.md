# 平局盲点分析与修复（2026-08-12）

## 1. 盲点量化

账本 192 场：实际平局 55 场（28.6%），但方向预测仅命中 1 场（1.8%）。
纯 argmax 永远只选 H/A（平局概率极少是最高），是结构性盲点。

## 2. 根源分析（三层）

1. **概率无区分度**：模型/市场平局概率在平局场 vs 非平局场均 ≈0.24-0.27，
   Cohen d ≈ 0（唯一有区分度的特征是 `xg_d`：平局场主队 xG 反而更高 1.76 vs 1.46）。
2. **isotonic 标定倒挂**：三路独立保序回归，平局样本少 + 输入无区分度 →
   学到噪声阶梯：final 平局P∈[0.25,0.30) 实际平局率 21% < [0.20,0.25) 的 36%。
3. **联赛异质性被忽略**：平局率跨联赛差异 5 倍（葡超 56%/美职联 55%/巴甲 50%
   vs 瑞超 11%/荷甲 11%）。

## 3. 修复 1：R1 改判规则（commit 92ba373）

- **规则**：高平联赛（芬超/瑞典超/美职联/巴甲/葡超，平局率>=40% 且 n>=5）
  + 市场平局P∈[0.20,0.30) → 无脑改判平局
- **回测**（137 场）：46.7% vs 基线 43.8%（+2.9pp），改判 34 场新得 17 丢 13
- **切半稳健**：前半 42.6% vs 41%，后半 50.7% vs 46%
- **触发场次质量**：34 场中实际平局 18 场（53%）
- **口径**：预测（_pick_direction）与两处结算回写完全一致；
  8/11 已结算 9 场 0 触发，不扰动历史

## 4. 修复 2：平局概率联赛锚定（commit c9ec6ac）

- **方案**：isotonic/temp 校准 + 新鲜度收缩后，高平联赛平局概率向实证平局率
  锚定：`final_d = 0.7*final_d + 0.3*league_anchor`，再归一化
- **锚定表**：瑞典超 0.60 / 美职联 0.55 / 葡超 0.50 / 巴甲 0.46 / 芬超 0.40
- **回测**（叠加 R1）：命中率保持 46.7%，Brier 0.6559 → 0.6434（全联赛版 0.6371）
- **保守设计**：只锚高平联赛，不碰欧冠/巴西杯等小样本低平联赛（避免错误收缩）
